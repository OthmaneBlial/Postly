real response.

A small local project you can inspect, change and commit.

Start with the right version.

The redesigned desktop and Orders starter are available in the public 0.2.0-preview.1 macOS Apple Silicon release. They are not in the older public v0.1.0 archive.

Download the DMG or tar archive, verify its checksum, and use the matching release notes. This preview is ad hoc signed and not notarized; fresh-machine, Windows/Linux and Intel macOS gates are still open. Do not assume every platform has a tested binary.

For the macOS preview DMG: verify its checksum, drag Postly to Applications and open it. Ad-hoc signing is not Apple notarization. Follow the per-app guidance in the installation, update and rollback guide; don't disable Gatekeeper globally.

Build from source.

Use Rust 1.95.0, as pinned in the repository. Compilation time depends on your machine; this is not a one-minute installation promise.

git clone https://github.com/OthmaneBlial/Postly.git
cd Postly
cargo build --locked --workspace
cargo run -p postly-app

Native build dependencies vary by OS. Consult the contributor guide. Optional Postman scripts require Node.js; normal requests and native assertions do not.

A working API, on your machine.

  1. Open Postly without a workspace path. Choose Try the example and an empty folder.
  2. Select 01 Health and press Send. Look for HTTP 200 and "status": "ok".
  3. Select 02 List orders. Send it to see two paid orders.
  4. Change the query parameter from paid to pending. Send again: one matching order.
  5. Save the request. Open Run collection to check saved requests and assertions.

The example API runs while its desktop session stays open. Your workspace stays on disk. To restart the API later, use postly demo --serve-only --port PORT with the port saved in the collection's baseUrl.

One project. Two ways to work.

With the current binaries on your PATH, create an example and leave its server running:

postly demo ./orders-demo --port 3979

In another terminal:

postly run ./orders-demo
postly run ./orders-demo --reporter json

The unchanged starter produces two passing requests and five passing assertions. If using a source build, replace postly with cargo run -- from the repository root.

Commit the files, change a parameter in the desktop and save, then inspect the ordinary Git diff:

cd orders-demo
git init
git add .
git commit -m "Add Orders API requests"
# Edit and save a request in Postly, then:
git diff
