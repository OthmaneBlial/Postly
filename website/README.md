# Postly project site

This is a dependency-free static showcase for Postly. It is intentionally kept
separate from the canonical Rust workspace and does not claim a deployed URL,
download count, benchmark advantage or full Postman parity.

Open index.html directly for a quick preview, or serve this directory locally:

~~~bash
python3 -m http.server 4173 --directory website
~~~

The page links back to the repository's README and documentation. Before any
future GitHub Pages deployment, verify the final base path, link targets,
mobile overflow, keyboard focus, reduced-motion behavior and browser console.
